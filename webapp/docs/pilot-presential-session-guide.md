# Navi · Guía de Operación para Sesión Presencial

## Antes de que lleguen los estudiantes

1. Entrar a `https://ruta-mentoria.vercel.app/admin`
2. Hacer `Traer de Sheets`
3. Abrir la pestaña `Vista general`
4. Mostrar el bloque de check-in
5. Tener visible el QR o el link de `https://ruta-mentoria.vercel.app/check-in`

## Cuando llega el estudiante

1. Pedir que escanee el QR o abra el link de check-in
2. Confirmar que capture su matrícula
3. Verificar si el sistema detecta diagnóstico previo
4. Si sí lo detecta, avanzar a selección de metas
5. Si no lo detecta, decidir:
   - responder el diagnóstico en ese momento
   - o continuar con apoyo del mentor

## Durante la conversación

- usar los resultados del diagnóstico como contexto
- elegir meta prioritaria
- elegir meta complementaria
- definir horizonte de tiempo
- trabajar obstáculo principal y respuesta al obstáculo

## Al cierre

1. Confirmar que el estudiante llegue a `/plan-accion`
2. Revisar que pueda descargar o copiar su plan
3. Si aplica, pedir que registre el plan en MiVidaTec

## Incidencias frecuentes

### La matrícula no aparece

- confirmar que fue escrita correctamente
- si persiste, escalar a coordinación

### El estudiante no tiene diagnóstico

- si hay tiempo, responder el diagnóstico
- si no hay tiempo, continuar con apoyo del mentor y dejar registro del caso

### El panel no refleja cambios

- usar `Traer de Sheets`
